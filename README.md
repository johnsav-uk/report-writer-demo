# Report Writer: demo

A demonstration of Report Writer, a report-writing tool for Microsoft 365, on an
invented school. **Every pupil, teacher and report here is synthetic.**

Open it at https://johnsav-uk.github.io/report-writer-demo/. The built-in demo
tidy works for anyone; the real AI (Google Gemini) needs the demo password.

This repository holds only the built page. It's replaced on each publish.
